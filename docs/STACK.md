# Stack

Final choices for the frontend and why. Anything different from the brief's recommended stack is
called out.

| Area          | Choice                                                                            | Notes                                                                                                                                                                                          |
| ------------- | --------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Runtime       | Expo SDK 57 (React Native 0.86, React 19.2), TypeScript strict                    | Development build with `expo-dev-client`, not Expo Go (native modules: MMKV, camera, Apple auth). New Architecture only. React Compiler enabled (SDK default).                                 |
| Navigation    | Expo Router 57 (file based)                                                       | `app/(onboarding)`, `app/(auth)`, `app/(tabs)`, `app/(modals)`. Typed routes on. Router root is `app/` at the project root as requested (the SDK 57 template default is `src/app`; both work). |
| Styling       | Typed tokens + `StyleSheet.create`                                                | NativeWind was not used: several measured values (1.5pt borders, 46/52/62pt sizes, 42-52pt line heights) do not map to Tailwind's scale without config noise. Tokens live in `src/theme`.      |
| Animation     | `react-native-reanimated` 4 + `react-native-gesture-handler`                      | All press feedback, selection, progress and counter animations run on the UI thread.                                                                                                           |
| Sheets        | `@gorhom/bottom-sheet` 5                                                          | Language picker and other sheets.                                                                                                                                                              |
| Lists         | `@shopify/flash-list` 2                                                           | Ingredient search, diet list, history.                                                                                                                                                         |
| Images        | `expo-image`                                                                      | Caching + blurhash placeholders.                                                                                                                                                               |
| State         | Zustand 5                                                                         | `onboardingStore`, `profileStore`, `appStore`.                                                                                                                                                 |
| Persistence   | `react-native-mmkv` 4 (Nitro)                                                     | Onboarding progress, language, profile draft. Wrapped in `src/store/storage.ts` so it can be swapped.                                                                                          |
| Data          | TanStack Query 5                                                                  | Mock services behind interfaces in `src/services`; `EXPO_PUBLIC_API_MODE=mock                                                                                                                  | real` switches implementations. |
| i18n          | i18next + react-i18next + expo-localization                                       | `src/i18n/locales/*.json`. Non-English files start as English copies with a TODO.                                                                                                              |
| Camera        | `expo-camera`                                                                     | Live preview, permission flow, torch, gallery via `expo-image-picker`. No recognition yet.                                                                                                     |
| Haptics       | `expo-haptics`                                                                    | Light impact on selection, medium on primary actions.                                                                                                                                          |
| Safe areas    | `react-native-safe-area-context`                                                  | No hard-coded status bar / home indicator heights.                                                                                                                                             |
| Auth          | `expo-apple-authentication`, `@react-native-google-signin/google-signin`          | Both wired to `MockAuthService`. Google needs client IDs before real use.                                                                                                                      |
| Fonts         | `@expo-google-fonts/inter` via `expo-font`                                        | Regular, Medium, SemiBold, Bold.                                                                                                                                                               |
| Blur          | `expo-blur`                                                                       | Language sheet backdrop.                                                                                                                                                                       |
| Gradient      | `expo-linear-gradient`                                                            | Loading bar green fade.                                                                                                                                                                        |
| Icons         | `@expo/vector-icons` (bundled with Expo) + `react-native-svg` for the Google mark | Single `Icon` component maps semantic names to glyphs.                                                                                                                                         |
| Network state | `@react-native-community/netinfo`                                                 | Offline banner.                                                                                                                                                                                |
| Lint / format | ESLint (`eslint-config-expo`) + Prettier                                          | `npm run lint`, `npm run format`.                                                                                                                                                              |
| Tests         | Jest (`jest-expo`) + React Native Testing Library                                 | Key UI components and stores.                                                                                                                                                                  |
