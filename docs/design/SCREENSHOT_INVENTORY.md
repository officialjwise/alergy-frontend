## Concepts from the references and how they are built (Phase 3)

The Phase 2 rule that replaced calorie and fitness concepts with allergy
equivalents was reversed by the product owner on 2026-09-17 ("make exact same
copy"). The table below records what is built literally and the few places
that still differ.

| Reference concept             | What we build                                                                                                   |
| ----------------------------- | --------------------------------------------------------------------------------------------------------------- |
| Calories, macros, budgets     | Built: per-serving nutrition on every product, daily goals, calorie budget with burned calories added back      |
| Weight, goal weight, BMI      | Built: weight log, goal date at a pound a week, BMI with the four-band scale                                    |
| Workouts and Apple Health     | Built behind `ActivityService`; the mock stands in for HealthKit until the native module is added               |
| Progress photos of the body   | Built as Progress Photos with the privacy notice; photos stay on the device                                     |
| Flame streak of logged days   | Built: a day counts when at least one food is logged                                                            |
| Milestone badges              | Built: the 30 badges with their names; "Nut Case" counts nut labels checked instead of nuts eaten (allergy app) |
| "Refer a friend and earn $10" | Built; title, body and code come from `src/config/app.ts`                                                       |
| Fitness community groups      | Unchanged: allergy and diet community groups plus private family groups                                         |
| Allergy features              | Kept in their own "Allergies & diet" section on Profile and in the verdict pill on every food row                |

The "Implemented by" column is filled in as each milestone lands, so every
reference points to exactly one route.
